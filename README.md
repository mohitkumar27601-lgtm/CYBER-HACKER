# CYBER HACKER - APK banane ke steps
1. GitHub par naya repo banao aur is poore folder ki files upload karo (`.github/workflows/build-apk.yml` ke saath).
2. Repo ke **Actions** tab mein "Build APK" khud chalega (ya **Run workflow** dabao).
3. 5-8 minute baad run khulo, neeche **Artifacts** mein `CYBER-HACKER-apk` download karo.
4. Zip kholo, `app-debug.apk` phone mein install karo (Unknown sources allow karna padega).
Game ki file: `www/index.html`. Icon: `assets/icon-only.png`.
